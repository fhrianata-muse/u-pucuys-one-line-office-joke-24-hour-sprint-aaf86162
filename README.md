One line, 109 characters — a joke about office life, the sort of line you
send a colleague after a meeting that should have been an email:

> I asked IT for a second monitor and got a second meeting instead — same screen, more people watching me work.

`main.py` holds the line as data, checks it against the 1–200 character
single-line gate at run time, and writes it to `/output/entry.txt`.
